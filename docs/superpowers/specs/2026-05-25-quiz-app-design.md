# 课程测验应用设计规格

**日期**: 2026-05-25
**状态**: 已确认
**项目类型**: 全新独立项目（纯前端 Web 应用）

---

## 1. 项目概述

一个基于课程教程的测验应用。用户导入 PDF/XLSX/PPTX 课程文件，AI 自动生成选择题，用户点击选项卡片答题，支持游戏化挑战。

### 目标用户
需要复习课程内容的学生或自学者

### 核心价值
将静态课程内容转化为互动测验，通过游戏化机制增加学习动力

---

## 2. 技术架构

### 技术栈
| 层 | 技术 |
|---|------|
| 框架 | React 18 + TypeScript |
| 构建 | Vite |
| 样式 | Tailwind CSS |
| PDF 解析 | pdfjs-dist |
| XLSX 解析 | xlsx (SheetJS) |
| PPTX 解析 | JSZip |
| AI 服务 | DeepSeek API / MiMo API |
| 存储 | localStorage |

### 部署
纯静态托管（Vercel / Netlify / GitHub Pages）

---

## 3. 核心流程

```
用户导入课程文件（PDF/XLSX/PPTX）
        ↓
   浏览器解析文件内容
        ↓
   调用 AI API 生成选择题
        ↓
   用户答题（点击选项卡片）
        ↓
   计分 + 连击 + 生命值
        ↓
   游戏结束 → 成绩统计 / 成就解锁
```

---

## 4. 文件解析模块

### 支持格式
| 格式 | 解析库 | 说明 |
|------|--------|------|
| PDF | pdfjs-dist | Mozilla 官方，纯前端 |
| XLSX | xlsx (SheetJS) | 行业标准 |
| PPTX | JSZip | 提取文本内容 |

### 解析流程
1. 用户拖拽或点击上传文件
2. 根据文件扩展名选择解析器
3. 提取纯文本内容（段落/单元格/幻灯片文字）
4. 按章节/页码分段，作为 AI 生成题目的上下文

---

## 5. AI 题目生成

### 服务配置
- 支持 DeepSeek 和 MiMo 两个服务
- 用户输入 API Key，存储在 localStorage
- 首次使用时选择服务并配置 Key

### Prompt 设计
```
你是一位专业的出题老师。根据以下课程内容，生成 N 道选择题。

要求：
- 每题 4 个选项（A/B/C/D），只有一个正确答案
- 附带答案解析
- 难度适中，覆盖重点知识

课程内容：
{chunk_text}

输出 JSON 格式：
[{
  "question": "题目内容",
  "options": ["A. ...", "B. ...", "C. ...", "D. ..."],
  "answer": "A",
  "explanation": "解析内容"
}]
```

### 题目数量
用户可选择每次生成 10/20/30 题

### 交互逻辑
- 点击选项卡片 → 立即判定对错
- 答对：选项变绿 +1s 后自动进入下一题
- 答错：选项变红 + 显示正确答案（绿色高亮）+ 生命值 -1
- 答案解析默认折叠，点击「查看解析」展开

## 7. 游戏化系统

### 计分 + 连击
- 答对基础分：+10 分
- 连击奖励：连续答对第 N 题，额外 +N×5 分（第 3 题连击额外 +15）
- 答错重置连击

### 生命值
- 初始 3 条命（❤️❤️❤️）
- 答错扣 1 条
- 生命归零 → 游戏结束
- 可选「无限生命」模式（练习模式）

### 成就系统（本地存储）
- 「初出茅庐」— 完成第一轮答题
- 「满分通关」— 全部答对
- 「连击大师」— 连击达到 10
- 「速度之王」— 20 题在 2 分钟内完成
- 「不屈之心」— 在只剩 1 命时通关

---

## 8. 数据存储

### 本地存储（localStorage）
- API Key 配置
- 成就解锁记录
- 历史成绩（课程名、得分、正确率、时间）

### 历史记录
- 每次游戏结束显示成绩卡片
- 可查看历史最高分、平均正确率
- 成就墙展示已解锁成就

### 不存储的内容
- 原始文件内容（每次重新解析）
- 生成的题目（不缓存，每次重新生成）
